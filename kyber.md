# Build and Run Commands

This document organizes the build and run commands for the different cryptographic schemes, algorithms, and configurations in the repository.

## Original

### KYBER-Apps

##### Kyber-512
```bash
make app-original-KEM-KYBER-kyber512 SCHEME=KEM ALG=KYBER VERSION=kyber512 ACC=original
make run-original-KEM-KYBER-kyber512 SCHEME=KEM ALG=KYBER VERSION=kyber512 ACC=original
```

##### Kyber-768
```bash
make app-original-KEM-KYBER-kyber768 SCHEME=KEM ALG=KYBER VERSION=kyber768 ACC=original
make run-original-KEM-KYBER-kyber768 SCHEME=KEM ALG=KYBER VERSION=kyber768 ACC=original
```

##### Kyber-512
